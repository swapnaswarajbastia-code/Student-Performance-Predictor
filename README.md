
# Student Performance Predictor

## Project Overview
This project predicts student academic performance using Machine Learning.

## Features
- Data Cleaning
- Data Processing
- Data Visualization
- Machine Learning Prediction
- Streamlit Web Application

## Input Features
- Attendance
- Maths Marks
- Science Marks
- English Marks
- Internal Marks

## Output
- Predicted Overall Score

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
